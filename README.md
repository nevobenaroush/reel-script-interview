# Reel Script Interview

סקיל לכתיבת תסריטים לרילס בעברית, דרך ראיון קצר וממוקד. הוא לא מתחיל לכתוב לפני שיש סיפור, דוגמה או ניסיון אמיתי של היוצר.

הסקיל כולל [בנק הוקים](references/hooks.md) שאפשר להתאים לקול ולניסיון של כל יוצר או יוצרת.

## מה הסקיל עושה?

1. שואל שאלה אחת בכל פעם כדי להבין אם הסרטון סיפורי או סרטון ערך, מה פורמט הצילום ומה הרעיון.
2. מבקש פרטים ודוגמאות אמיתיות במקום להמציא סיפורים, מספרים או תוצאות.
3. מציע שלושה הוקים מתוך בנק ההוקים ומחכה לבחירה.
4. כותב תסריט מילה במילה או הוק עם נקודות, לפי בחירת המשתמש.
5. בודק שהניסוח נשמע כמו הדיבור של היוצר ומתקן בהתאם.

הפלט הוא טקסט מדובר בעברית. הוראות צילום, כתוביות והאשטגים נוספים רק אם מבקשים אותם.

## התקנה

אפשר להוריד את הריפו כ־ZIP או לשכפל אותו עם Git. יש להשאיר את `SKILL.md` ואת `references/hooks.md` יחד באותה תיקייה.

**Codex:** העתיקו את תיקיית `reel-script-interview` אל `~/.agents/skills/`.

**Claude Code:** העתיקו את התיקייה אל `~/.claude/skills/`. לשימוש בפרויקט יחיד, אפשר לשים אותה בתוך `.claude/skills/` בפרויקט.

## שימוש

לאחר ההתקנה, פתחו שיחה חדשה ובקשו למשל:

> תראיין אותי ותעזור לי לכתוב ריל על משהו שלמדתי השבוע.

הסקיל יתחיל בשאלות ויבנה את התסריט מתוך התשובות שלכם. ההנחיות המלאות נמצאות ב־[SKILL.md](SKILL.md).
